# Luna

For a feature, use the repo skill at `.agents/skills/luna-feature/SKILL.md`. Discuss the research, plan and acceptance criteria before implementing the feature. Use a separate worktree and a `codex/<feature>` branch. Commit and push each reported implementation checkpoint to that branch and use a PR for the default branch.

Run the agreed tests against the exact candidate and its current base. Merge only when the evidence and required GitHub checks are complete. Keep private conversations, credentials, raw traces and voice samples out of GitHub. Use the isolated evaluation stack for synthetic runs.
